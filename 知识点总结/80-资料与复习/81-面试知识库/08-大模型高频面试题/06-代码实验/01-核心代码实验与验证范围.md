# 核心代码实验与验证范围

这组实验把面试原理变成可观察、可断言的行为，使用 Python 标准库与 NumPy，在 CPU 上运行，不需要模型权重或 API Key。

## 运行

进入当前目录后执行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -v
```

运行测试不会下载模型，不会调用远程服务。依赖安装需要网络；也可以直接使用已装 NumPy 的 Python。验证环境为 Python 3.12.14、NumPy 2.3.5。

## 文件与覆盖

- [core_examples.py](core_examples.py)：闭包、算法、预处理、数值稳定 softmax、因果注意力、LayerNorm/RMSNorm、RoPE、LoRA、KV Cache、SFT 掩码与 shift、DPO/GRPO/PPO、RRF、检索指标、BIO、工具校验、异步限流、SSE、SQLite 只读查询、CLIP 对齐、扩散加噪。
- [project_examples.py](project_examples.py)：客服路由、商品去重、引用 ID 校验、先修关系环检测、租户权限与文档版本过滤。
- [test_core_examples.py](test_core_examples.py) 与 [test_project_examples.py](test_project_examples.py)：37 项行为与边界测试。
- [test-results.log](test-results.log)：本次实际运行记录。

## 关键不变量

因果注意力的未来权重必须为零；LoRA 显式分支应与权重合并结果一致；同位置 RoPE 旋转保留点积；测试集不能参与预处理拟合；无效回答 token 不参与损失；DPO 目标随相对参考的偏好间隔变化；同组相同奖励的 GRPO 优势为零；RRF 不重复计算同一路榜单的相同 ID；检索结果重复不能虚增 Recall；租户或版本不匹配的块不能进入候选。

## 验证边界

本次 37 项 CPU 测试全部通过，验证的是上述机制和契约。NumPy 目标函数没有自动求导、优化器或 rollout，因此不是完整训练实现。SQLite 例子验证只读限制，不包含生产表列授权、查询成本、租户隔离或完整 SQL 语义分析；引用 ID 存在也不等于其内容支持结论。

笔记内 PEFT、LangGraph 的 Python 模板已用 AST 检查语法，Neo4j Cypher 模板仅核对官方语义；这些框架与数据库均未实跑。原文的 PyTorch、Dify、Coze、Rasa 等项目代码全部按资料保留，未冒充已完成端到端部署。
