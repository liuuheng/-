
访问docker中的集群：

```PROPERTIES
宿主机本地程序访问 Kafka：localhost:9092
Docker 容器内部访问 Kafka：kafka:29092
```

也就是说，在你的 Mac 上跑 Java/Flink 程序时用：
```properties
kafka.bootstrap.servers=localhost:9092
```

提交到 Docker 里的 Flink 集群运行时用：
```PROPERTIES
kafka.bootstrap.servers=kafka:29092
```


---

进入到docker的kafka 中

```PROPERTIES
docker exec -it kafka bash
kafka 是docker中的容器名称
```

kafka查询的topic

```properties
[appuser@kafka bin]$ kafka-topics --bootstrap-server localhost:9092 --list
__consumer_offsets
orders
```


创建 topic：
```
kafka-topics \
  --bootstrap-server kafka:29092 \
  --create \
  --if-not-exists \
  --topic kujiale_design_events \
  --partitions 1 \
  --replication-factor 1
```

删除topic
```
kafka-topics --bootstrap-server kafka:29092 \
  --delete \
  --topic kujiale_design_events
```
  
查询所有 topic：
```
kafka-topics \
  --bootstrap-server kafka:29092 \
  --list
```
查看某个 topic 详情：
```
kafka-topics \
  --bootstrap-server kafka:29092 \
  --describe \
  --topic kujiale_design_events
```
启动消费者，从头开始消费历史消息：
```
kafka-console-consumer \
  --bootstrap-server kafka:29092 \
  --topic kujiale_design_events \
  --from-beginning
```
启动消费者，只消费启动之后的新消息：
```
kafka-console-consumer \
  --bootstrap-server kafka:29092 \
  --topic kujiale_design_events
```
如果 kafka:29092 不通，试这个：
```
kafka-topics --bootstrap-server localhost:9092 --list
```
对应消费者：
```
kafka-console-consumer \
  --bootstrap-server localhost:9092 \
  --topic kujiale_design_events \
  --from-beginning
```
