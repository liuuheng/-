# 数仓层面：埋点爬虫识别手段

> 适用场景：Web 埋点明细表，字段包含 `ip、ua、anonymous_id、user_id、session_id、event_id、client_ts、server_ts、event_name、url_path`。  
> 输出目标：在 DWD 明细层打标签 `bot_score / is_bot / is_preview / bot_reason / rule_version`，ADS 指标层默认剔除 `is_bot=1`。

---

## 0. 基本约定

**输入表（示例）**：`ods_events`
- 字段：`ip, ua, anonymous_id, user_id, session_id, event_id, client_ts, server_ts, event_name, url_path`

**输出表（示例）**：`dwd_events_with_bot_flag`
- 新增字段：`bot_score, is_bot, is_preview, bot_reason, rule_version`

**时间窗约定**
- 1 分钟窗：用于速率检测
- 5 分钟窗：用于更稳健的高频/覆盖检测
- 会话窗：按 `session_id` 聚合（没有 session_id 时可用 `anonymous_id + 时间分箱` 近似）

---

## 1) UA 正则识别（强规则：命中即高风险）

**伪代码**

```text
ua_lower = to_lower(ua)

如果 ua_lower 匹配正则 (bot|crawler|spider|scrapy|curl|wget|httpclient|python-requests|go-http-client|okhttp|aiohttp)
  bot_score += 80
  bot_reason 追加 "UA_脚本/爬虫关键词"

如果 ua_lower 匹配正则 (headless|phantomjs|selenium|puppeteer|playwright)
  bot_score += 100
  bot_reason 追加 "UA_自动化/无头浏览器"

如果 ua_lower 匹配正则 (slackbot|facebookexternalhit|twitterbot|telegrambot|whatsapp|discordbot|skypeuripreview|linkedinbot)
  is_preview = 1
  bot_reason 追加 "UA_社交/预览机器人"

如果 ua 为空 或 长度 < 20
  bot_score += 40
  bot_reason 追加 "UA_缺失/过短"
```

**备注**
- `is_preview` 建议单独口径（通常剔除业务指标，但保留审计/排查用）。

---

## 2) 高频/速率异常（聚合阈值：最通用）

### 2.1 按 IP 的 1 分钟速率

```text
对 ods_events 按 (minute_bucket(server_ts), ip) 聚合：
  cnt_1min_by_ip = count(*)

如果 cnt_1min_by_ip >= IP_1MIN_HARD_THRESHOLD
  对该 (minute_bucket, ip) 下的所有事件：
    bot_score += 40
    bot_reason 追加 "速率_IP_1分钟超阈值"
```

### 2.2 按匿名ID的 1 分钟速率

```text
对 ods_events 按 (minute_bucket(server_ts), anonymous_id) 聚合：
  cnt_1min_by_aid = count(*)

如果 cnt_1min_by_aid >= AID_1MIN_HARD_THRESHOLD
  bot_score += 40
  bot_reason 追加 "速率_匿名ID_1分钟超阈值"
```

### 2.3 更稳健做法：分位阈值（p99.9 / p99.99）

```text
先用近 7/14 天数据为每类聚合指标建立基线：
  baseline_p999_ip_5min = p99.9(cnt_5min_by_ip)

如果 cnt_5min_by_ip > baseline_p999_ip_5min
  bot_score += 30
  bot_reason 追加 "速率_IP_5分钟超P99.9"
```

---

## 3) 覆盖度异常（“扫站”特征：高频 + 高页面覆盖）

```text
对 ods_events 按 (5min_bucket(server_ts), ip) 聚合：
  cnt_5min = count(*)
  pages_5min = count_distinct(url_path)

如果 cnt_5min 很高 且 pages_5min >= PAGES_COVER_THRESHOLD
  bot_score += 30
  bot_reason 追加 "覆盖度_IP_短时访问页面过多"
```

也可对 `anonymous_id` 或 `ua` 做同样聚合。

---

## 4) 会话质量异常（短时长 + 高事件/高页面）

```text
对 ods_events 按 session_id 聚合：
  sess_events = count(*)
  sess_pages  = count_distinct(url_path)
  sess_duration = max(client_ts) - min(client_ts)   # 没有 client_ts 就用 server_ts

如果 sess_duration <= 2秒 且 sess_events >= 30
  bot_score += 50
  bot_reason 追加 "会话_2秒内事件过多"

如果 sess_duration <= 10秒 且 sess_pages >= 20
  bot_score += 40
  bot_reason 追加 "会话_短时访问页面过多"
```

---

## 5) 重复/重放检测（event_id / client_ts）

### 5.1 event_id 重复（强证据）

```text
对 ods_events 按 (5min_bucket(server_ts), anonymous_id) 聚合：
  total = count(*)
  uniq_event = count_distinct(event_id)
  dup = total - uniq_event

如果 dup >= 5
  bot_score += 60
  bot_reason 追加 "重放_event_id_重复过多"
```

### 5.2 client_ts 异常重复（补充证据）

```text
对 ods_events 按 (1min_bucket(server_ts), anonymous_id, client_ts) 聚合：
  same_ts_cnt = count(*)

如果 same_ts_cnt >= 10
  bot_score += 30
  bot_reason 追加 "重放_client_ts_相同时间戳重复"
```

---

## 6) 链路/序列合理性（无交互直达关键事件、跳步）

> 需要你们定义：  
> - `INTERACTION_EVENTS`：交互类事件集合（例如 click/scroll/input 等）  
> - `CONVERSION_EVENTS`：关键转化类事件集合（例如 order_submit/pay_success 等）

```text
对 ods_events 按 session_id 聚合：
  has_interaction = 是否存在 event_name ∈ INTERACTION_EVENTS
  has_page_view   = 是否存在 event_name = "page_view"（或你们的页面浏览事件）
  has_conversion  = 是否存在 event_name ∈ CONVERSION_EVENTS

如果 has_conversion = 真 且 (has_interaction = 假 或 has_page_view = 假)
  bot_score += 60
  bot_reason 追加 "链路_无交互/无浏览却转化"

（可选）对同会话事件按 client_ts 排序：
  如果 转化事件时间 < 页面浏览时间
    bot_score += 60
    bot_reason 追加 "链路_事件顺序不可能"
```

---

## 7) 最终判定与输出（推荐：强规则 + 打分阈值）

```text
BOT_THRESHOLD = 60

is_bot = (bot_score >= BOT_THRESHOLD)

输出到 dwd_events_with_bot_flag：
  追加字段 bot_score, is_bot, is_preview, bot_reason, rule_version
```

---

## 8) 指标层（ADS）使用口径建议

```text
业务默认口径：
  where is_bot = 0 and is_preview = 0

同时保留：
  原始口径（含 bot/preview）用于排查与审计
```
