### 1) 核心概念：AARRR、漏斗、北极星指标（NSM）

#### 1.1 AARRR 是什么（增长框架）

**AARRR（海盗指标）**把用户从“第一次接触产品”到“长期价值与传播”的路径拆成 5 段：

- **Acquisition 获取**：用户从哪里来，渠道效率与质量如何  
- **Activation 激活**：用户第一次真正获得核心价值（Aha 时刻）  
- **Retention 留存**：用户是否持续回来、形成复用与习惯  
- **Revenue 变现**：价值如何转成收入（付费/续费/增购等）  
- **Referral 传播**：用户是否愿意分享并带来新用户/新线索

它的重点不在“把所有指标都看一遍”，而在于：**把增长拆成可诊断的阶段，找短板，做实验迭代**。

#### 1.2 你为什么会觉得它像“不同层级的漏斗”（你的直觉为何正确）

你的感觉可以更精确地表述为：

- **AARRR 本质是「按用户生命周期分阶段」的指标框架**  
- 每个阶段内部都可以用 **漏斗分析**去拆解（所以看起来像“不同层级的漏斗”）

两者关系可以这样区分：

- **漏斗分析（Funnel）**：一种分析方法/工具  
  - 关注一条路径里：A→B→C，每一步掉多少、卡在哪里
- **AARRR**：一种增长拆解框架/指标体系  
  - 关注五个阶段：哪一段是短板、该为哪段建立漏斗与指标、先优化哪里

所以你说的“不同层级”在常用术语里更接近：

- **用户生命周期（Lifecycle）分阶段**
- **分段漏斗 / 漏斗链（Funnel chain）**
- **指标体系 / 增长模型（Metrics framework）**

#### 1.3 北极星指标（NSM）是什么（以及它和 AARRR 的关系）

我们给出的定义是：

- **北极星指标（NSM）**：衡量产品“**核心价值被用户持续获得**”的**一个主指标**  
- **AARRR**：用来解释并拆解 NSM 的驱动因素（获取/激活/留存/变现/传播分别怎么贡献）

常用结构（不强求公式，但便于理解）：

- NSM 往往可以拆成：**人（活跃用户）× 行为次数 × 行为质量/成功率**

提醒：

- NSM 不应是“空泛活跃”（如只看 DAU）  
- 要能代表核心价值、能拆解、能被产品影响、且不易被刷

### 2) 两种层级指标：阶段 KPI vs 步骤指标（为何看起来不一样）

你看到“不一样”是正常的：我们讨论的是**两种层级的指标**，用途不同但彼此互相解释。

#### 2.1 两种层级：阶段 KPI（看板用） vs 步骤指标（诊断用）

- **阶段 KPI / 人群分层指标（Stage KPI）**
  - 特点：少、稳、适合做周报/看板，回答“这一段整体好不好”
  - 例子：注册数、全站活跃、工具活跃、渲染活跃、会员付费
- **步骤指标 / 漏斗拆解指标（Step Metrics）**
  - 特点：更细、可诊断，回答“为什么不好、卡在哪一步、该改哪里”
  - 例子：进入工具 → 查找模型 → 点击模型 → 添加到方案 → 渲染成功 → 保存/分享（各步转化率/耗时/失败原因）

你可以把它理解成：

- **阶段 KPI**用来“发现问题/衡量结果”
- **步骤指标**用来“解释问题/定位改动点”

#### 2.2 你那组指标分别属于哪一层（以及在 AARRR 中大概对应哪一段）

以你给出的指标为例：

- **用户注册**：更偏**阶段 KPI**（Acquisition 的结果口径：新增用户）
- **全站活跃**：更偏**阶段 KPI**（Retention 的宽口径：广义活跃/回访）
- **工具活跃（进入云图工具）**：更偏**阶段 KPI**或“激活前置门槛”（Activation 漏斗早期步骤）
- **渲染活跃（生成过渲染内容）**：更偏**阶段 KPI**，也是 Activation 的 **Aha 候选**（首次价值更可能发生在渲染/保存/分享等成果事件上）
- **会员付费（购买成功）**：更偏**阶段 KPI**（Revenue 核心事件）

补充说明：

- 这组指标适合作为“最小链路看板”，但当你要回答“为什么工具活跃高但渲染活跃低/为什么首版方案时间变长”时，就需要引入更细的**步骤级漏斗**来拆解原因。

### 3) 酷家乐语境下的 AARRR（围绕“产出物”）

我们当时强调了一个酷家乐场景的核心特点：

> 酷家乐的价值高度依赖“**可视化成果/交付物**”：方案、渲染图/全景、报价/清单、营销素材。  
> 因此 AARRR 的事件与指标要围绕“产出物”定义，而不是围绕“登录/注册”这种弱价值动作。

下面分 ToC（业主）与 ToB/ToPro（门店/设计师/品牌）两条常见主线描述。

#### 3.1 Acquisition 获取（从哪里来 + 质量如何）

- **ToC（业主）常见来源**：内容平台（装修攻略/效果图）、SEO（户型/风格/预算/报价）、朋友分享回流、应用市场
- **ToB/ToPro 常见来源**：平台招商/官网线索、渠道商/行业活动、线下培训与社群、品牌总部推动

**关键点（我们反复强调过）**：  
不要只看“注册量/访问量”，而要看 **有效新增**与**渠道质量**（例如：激活率、7 日留存、线索质量、付费/LTV）。

#### 3.2 Activation 激活（第一次获得价值：Aha 事件怎么定义）

原则：

- **激活不是“注册成功”**  
- 激活应定义为：**第一次产出“可用成果”**（能沟通、能交付、能推动下一步）

**ToC 激活事件例（偏“看得见的成果”）**

- 导入/画户型 → 放置关键家具/柜体 → **首次渲染成功并保存/分享（首张可用效果图/全景）**

**ToB/ToPro 激活事件例（偏“能签单/能交付”）**

- 新门店/设计师在一定时间内跑通：  
**客户/线索建立 → 方案创建 → 出图/全景 →（可选）清单/报价**  
重点是：形成“可跟进、可交付”的首版成果。

常见衡量（用于做漏斗与优化）：

- **激活率**：新用户在 24h/72h/7d 内完成激活事件的比例  
- **TTV（Time to Value）**：从首次进入到首次获得价值的时间  
- **新手漏斗**：进入编辑器→户型→摆放→渲染→保存/分享（逐步定位卡点）

#### 3.3 Retention 留存（持续回来靠什么）

两种典型留存驱动：

- **ToC（项目迭代驱动）**：反复改布局/风格/材质、预算调整、与家人讨论对比
- **ToB（工作流依赖驱动）**：每天有线索、持续出图报价、团队协作、资产沉淀（模板/模型/报价规则等）

常见指标方向：

- D1/D7/D30 留存、回访频次  
- 方案的编辑/版本迭代次数  
- 分享后回流、协作访问等

#### 3.4 Revenue 变现（把价值卖出去）

典型变现逻辑：

- ToC/ToB 的共同点：把“更高质量/更高效率/更可交付”的能力做成付费点  
  - 更快/更清晰的渲染、更高画质、更高额度  
  - 更可交付：施工图/深化、清单/报价、对接供应链  
  - ToB 管理：协作、权限、资产库、集成等

核心强调：

- 付费点要对齐“业务结果”（例如：更快出首版 → 更多邀约/更高成交概率），而不只是堆功能名词。

#### 3.5 Referral 传播（为什么酷家乐天然适合）

传播优势来自“产物天然可分享”：

- **ToC**：晒成果/征求意见（效果图、全景、短视频）
- **ToB**：给客户看方案、朋友圈获客、展示专业度（方案链接、成交海报）

指标方向：

- 分享率、分享→点击→回流→注册/激活的链路转化  
- 对 ToB 更关心：分享触达客户数、回访与留资/线索质量

### 4) “缩短方案时间”作为北极星指标：口径、拆解、护栏

你给出的明确目标是：**缩短方案时间**。我们给出的是偏“可落地埋点”的 NSM 定义。

#### 4.1 推荐 NSM（最贴目标）

- **首版方案交付时长的中位数（P50）**  
从开始到首版可交付的耗时，取中位数以避免极端案例拉偏平均值。

> 你也可以同时看 P75/P90 做“长尾治理”，但主指标用 P50 更稳定。

#### 4.2 Start/End 必须事件化（否则口径会漂）

我们建议把“方案时间”变成一个可计算的区间：

- **Start（推荐）**：第一次进入编辑器（更贴近“真正开始做方案”）
- **End（候选）**：首次“可交付”的明确事件  
  - 首次渲染成功 + 保存方案  
  - 或首次分享给客户/生成链接  
  - 或首次导出交付物（图/全景/清单/报价）

最常用、低歧义组合：

- **Start=第一次进入编辑器**
- **End=首次渲染成功并保存（或分享）**

#### 4.3 只压时长会带来“糊弄首版”的风险：要加护栏（Guardrails）

至少并行看 2~3 个质量护栏，避免“时间变短但质量变差”：

- **返工/版本数**：首版后 7 天内的修改次数（过高可能首版质量不足或沟通不清）
- **客户反馈代理**：分享链接打开率、停留时长、二次回访
- **业务阶段推进代理**：首版后进入下一阶段（邀约/复尺/报价/成交）的转化（如果能拿到）

#### 4.4 用 3 段拆解定位瓶颈（最实用落地法）

把总时长拆成三段分别看中位数（或分位数）：

- **进入编辑器 → 户型准备完成** 的 P50  
- **户型准备完成 → 首渲染成功** 的 P50  
- **首渲染成功 → 可交付（保存/分享/导出）** 的 P50

这样你能快速回答：时间主要卡在 **建模/渲染/交付** 哪段，而不是只看到一个“总时长”。

### 5) 附：每个阶段内部如何用漏斗分析拆解（阶段内漏斗示例）

这句话的意思是：AARRR 把增长分成 5 个阶段（获取/激活/留存/变现/传播），但每个阶段要完成的事都需要经过多个动作，因此**每个阶段内部都能画出一条“步骤 → 步骤 → 结果”的漏斗**，用来定位卡点与流失点。

你可以把它理解成：

- **AARRR 是目录**：告诉你要关注哪 5 类问题
- **漏斗分析是放大镜**：把其中一类问题拆成具体步骤，回答“掉在哪一步”

下面结合酷家乐给每段各举一条典型“阶段内漏斗”。

#### 5.1 Acquisition（获取）阶段内漏斗：从流量到“有效新增”

曝光 → 点击 → 落地页到达 → 注册/登录 → 首次进入工具（有效新增）

阶段内漏斗要回答的问题：

- 哪个渠道在“落地页→注册”掉得最多？
- 哪个渠道“注册了但不进工具”（新增质量差）？

#### 5.2 Activation（激活）阶段内漏斗：从“进工具”到“首次价值（Aha）”

进入云图工具 → 导入/创建户型 → 查找模型 → 点击模型/分类 → 添加到方案 → 渲染成功 → 保存/分享（首次价值）

阶段内漏斗要回答的问题：

- 新手卡在“找不到模型/不会添加/渲染失败或太慢/不知道下一步”哪一段？
- 哪个步骤的转化率最低，导致 TTV 变长？

#### 5.3 Retention（留存）阶段内漏斗：从“回来”到“持续价值行为”

第 7 天回访 → 进入工具 → 编辑方案 → 再次渲染/保存 → 分享给客户/家人

阶段内漏斗要回答的问题：

- 用户回来了但没进入工具，问题在触达/入口还是需求消失？
- 进入工具但不再编辑/渲染，问题在内容供给、模板复用还是性能体验？

#### 5.4 Revenue（变现）阶段内漏斗：从意愿到付费成功/续费

触达付费墙（渲染额度不足/高清导出）→ 查看价格页 → 发起支付 → 支付成功 → 使用权益 → 续费

阶段内漏斗要回答的问题：

- 掉在价格页（价值表达/套餐设计）还是支付链路（支付方式/失败重试）？
- 付费后不使用导致不续费（价值交付不足）？

#### 5.5 Referral（传播）阶段内漏斗：从分享到账面可归因的新增

生成分享链接/作品 → 分享出去 → 被点击打开 → 新用户注册 → 新用户激活（渲染成功）

阶段内漏斗要回答的问题：

- 是没人分享（动机不足/入口不明显），还是分享了没人点（素材不适配/承诺不清晰）？
- 点了但不注册/不激活（落地页与产品体验问题）？

#### 5.6 阶段指标 vs 阶段内漏斗（一个很重要的区分）

- **阶段指标**：用一句话衡量这段好不好（如激活率、D7 留存率、付费转化率）
- **阶段内漏斗**：解释“为什么不好”，告诉你应该改哪一步（如渲染成功率低、分享点击率低、支付发起到成功掉点高）

一句话概括：
**AARRR 负责划分战场（优化哪一段），漏斗分析负责拆解战术（这段里具体改哪一步）。**

---

### 6) 一句话总结（最终串联）

- **北极星指标**：首版方案交付时长（P50）持续下降（同时守住质量护栏）。  
- **AARRR 的作用**：用获取质量、激活 TTV、新手漏斗卡点、留存带来的资产复用、变现与传播链路，去解释并驱动这个 NSM 的改善。

---

### 7) 关键提醒（避免跑偏）

- **AARRR ≠ 一个漏斗**：它是“分阶段的漏斗链 + 生命周期视角”  
- **激活（Activation）是最关键的定义工作**：尤其在酷家乐这种“价值来自产出物”的产品里  
- **NSM 与 AARRR 的关系是‘目标—拆解’**：NSM 定方向，AARRR 帮你拆到可优化的段落与实验  
- **“缩短方案时间”不是一句话指标**：必须给出 Start/End 事件，且要加质量护栏，避免指标被刷或诱导坏行为
