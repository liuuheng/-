
mac 如何让 访达显示 .开头的文件
按快捷键：

**`Command + Shift + .`**

再按一次恢复隐藏，是个开关。

# IDEA Mac 常用快捷键

## 搜索

| 功能 | 快捷键 |
| --- | --- |
| 当前文件搜索 | Command + F |
| 全项目搜索 | Command + Shift + F |
| 搜索类 | Command + O |
| 搜索文件 | Command + Shift + O |
| 万能搜索 | Shift + Shift |
| 搜索动作 | Command + Shift + A |

## 代码编写

| 功能 | 快捷键 |
| --- | --- |
| 代码补全 | Control + Space |
| 智能补全 | Control + Shift + Space |
| 快速修复 / 自动导包 | Option + Enter |
| 查看方法参数 | Command + P |
| 格式化代码 | Command + Option + L |
| 生成代码 | Command + N |

## 重构

| 功能 | 快捷键 |
| --- | --- |
| 引入变量 | Option + Command + V |
| 引入常量 | Option + Command + C |
| 引入字段 | Option + Command + F |
| 重命名 | Shift + F6 |

## 跳转

| 功能 | 快捷键 |
| --- | --- |
| 跳转到定义 | Command + B |
| 鼠标跳转到定义 | Command + 鼠标点击 |
| 返回上一个位置 | Command + Option + 左箭头 |
| 前进到下一个位置 | Command + Option + 右箭头 |

## 运行和调试

| 功能 | 快捷键 |
| --- | --- |
| 运行当前类 | Control + Shift + R |
| Debug 当前类 | Control + Shift + D |
| 打断点 / 取消断点 | Command + F8 |
| 单步跳过 | F8 |
| 单步进入 | F7 |
| 跳出方法 | Shift + F8 |

如果 F1、F7、F8 不能直接使用，尝试加 fn。

## 编辑

| 功能 | 快捷键 |
| --- | --- |
| 删除当前行 | Command + Delete |
| 复制当前行 | Command + D |
| 移动当前行 | Shift + Option + 上/下箭头 |
| 当前文件替换 | Command + R |
| 全项目替换 | Command + Shift + R |
