# 选股后各阶段的情景应对

> [!info] 阅读口径
> 本篇为跨条目的综合整理，不是Z哥原话；对应原库全文保存在各主题章节的“原库理论详解”中。原库属于特定交易方法论，收益、胜率、案例与市场判断未经本次独立核验。不得用情景表填补原库缺失的规则。

## 情景应对的使用方法

本篇按“已选股、准备买、已持有、准备退出”组织分支。动作均指原库方法的条件式整理，不针对任何现实账户或当前标的。先确定自己使用的周期和策略，再查该分支；具体阈值冲突见 [[19-规则冲突与知识缺口]]。

每次判断按“环境→结构→信号→价格与时间失效→仓位动作”检查。下表不能单独证明洗盘、出货或主力身份，原库未规定的地方保留未知。

## 已选出股票，但还没有买入

| 情景 | 先核对什么 | 原库对应的应对与原因 |
|---|---|---|
| 01. 图很美，但大盘进入空头 | 活跃市值语境、大盘与个股周期 | 主流程暂停开仓，空头容错下降，不能靠图形豁免择时 |
| 02. 指数平稳，池内个股持续阴跌 | 个股白黄线、低点、量能与流动性 | 单独剔除无序或破位票；指数平稳不证明个股强 |
| 03. J已小于13，但前面没有异动 | 是否真有上涨N型、建仓量能 | 仅指标超卖不构成完整B1，继续观察或放弃 |
| 04. 长期下跌后开始横盘 | 周线高低点、均线是否仍空头 | 警惕大爷图，下跌中继不能直接当企稳反转 |
| 05. 放量长阳只有一天，后面无延续 | 60日线位置、连续两三次异动 | 单根不足以确认持续建仓，不为热闹入场 |
| 06. 建仓波已涨50%以上 | 涨幅起止点是否同一建仓波 | 两个30%专页要求放弃，不只看当前J低 |
| 07. 相关阳线累计换手超过40% | 统计的是累计而非单日 | B1页视为废B1，不能借“高换手活跃”覆盖 |
| 08. 日线B1好看，但周线空头 | 长周期趋势 | 多头控盘与主题过滤不通过；不把短期反弹当趋势 |
| 09. 周线上涨，但周B1未出现 | 当前是主题还是主线，是否只缺周信号 | 主题可用日B1，但仍要周线趋势；主线原库更偏好周B1 |
| 10. 候选上涨很强，离白线很远 | 所处波段及剩余风险收益空间 | 等回调或新确认，避免追入加速末端；已有仓另查放飞 |
| 11. 长上影、跳空或杂乱长影很多 | 选用B1、砖形还是其他专用策略 | 标准B1/DSZ优选会排除；不随意改称“特殊形态” |
| 12. 没找到完美图，但怕踏空 | 有无真正达到原规则的候选 | 空仓也是策略，不把每日选股变成每日必须买入 |

依据：本组主要综合异动选股、三最、B1、两个30%、死亡K线与择时条目，详见 [[02-择时过滤与市场环境]]、[[03-选股后验证与候选池管理]]、[[06-B1入场与建仓波鉴别]]。

## 买点出现和计划执行时

| 情景 | 先核对什么 | 原库对应的应对与原因 |
|---|---|---|
| 13. 买少妇战法，J只有5 | 用的是通用B1还是严格SOP | 通用J<13可达指标条件，但严格少妇要求J<-10，不能混称严格信号 |
| 14. 开盘量比<10 | 是否已有完美图形、观察时点 | 量比战法等回调，当天不抱爆发期待，不急于追高 |
| 15. 量比>20且红盘 | 高开幅度、位置、原策略禁区 | 原库优先关注强者，但高开4点以上等禁区仍要核对，不能单指标越权 |
| 16. 30秒急冲5—6个点 | 是否有事前计划，是否是分时冲动 | 原库不追这种快速冲高，避免没有成本与止损优势 |
| 17. B2涨幅只有3.96% | 是否按B2五条标准命名 | 该标准不达4%就不算，不能为了参与改阈值 |
| 18. B2量比前日只增加10% | 使用哪个B2页面版本 | “大于前日”版可能满足，“增加20%”版不满足；记录冲突，不假装统一 |
| 19. 突破后次日阴量接近3/4 | 原突破是否有效、阴线低点、旧止损 | 原库视假突破预警，按事前失效位防守，不默认强洗 |
| 20. 次日阴量不到1/2 | 结构及止损是否仍在 | 可作为洗盘候选，但不能证明一定成功；若破硬止损仍退出 |
| 21. 看见B3，不知道买还是减 | 是单根中继确认还是大波段冲刺 | 必须分清语境；不根据同名术语直接决定 |
| 22. 想补票，但没有红白资金副图 | 指标定义与数据 | 无法核验>80/<20或>85/<30，只能研究形态，不声称信号成立 |
| 23. 信号很好，但止损离入场太远 | 所选策略风险区间和结构失效位 | 不通过移动止损凑比例；可放弃，原库未提供统一仓位公式 |
| 24. 不知道用哪个周期止损 | 入场策略是超短、日波段还是周底仓 | 先完成计划再行动，不在被套后换周期 |

依据：本组综合B1/B2/B3、量比、少妇、补票与执行条目，详见 [[07-B2与B3确认及假突破应对]]、[[08-特殊买点与止损后重新入场]]、[[10-盘中执行与止损计划]]。

## 买入后立刻涨、不涨或下跌

| 情景 | 先核对什么 | 原库对应的应对与原因 |
|---|---|---|
| 25. 买后即涨，迅速脱离成本 | 嘀嘀参考位、是否进入加速/放飞阶段 | 保留风控，达到对应放飞条件再处理，不能因盈利取消计划 |
| 26. 普通B1三天不涨 | 是否原本使用普通B1时间版本 | 按该版退出或减仓；额外1—2天仅为另一原库口径，不能自动续期 |
| 27. B2买后两天都没涨 | 买入日是否计为第一天 | 专页先减50%，第三天还不涨清；破N低点更早直接退出 |
| 28. DSZ次日早盘未见预期 | 是否确实为DSZ超短 | 专页9:37前处理，不改用B1三天或长期底仓来拖 |
| 29. 曾经有浮盈又回成本下 | 盈利转负是否已触发所选规则 | 七层应对要求退出；量比页有砍掉或减半，版本需事前固定 |
| 30. 盘中突然急杀，但未破止损 | 位置、量能、趋势、是否S1 | 多头波段可按忍一根/尾盘修复观察，禁止情绪化追加仓位 |
| 31. 急杀已破预设硬止损 | 是真实触发还是数据/周期误读 | 原库按止损执行，“忍一根”不能豁免 |
| 32. 次日企稳或收复前阴一半 | 旧止损是否已触发、原结构是否仍有效 | 未触发者按持仓补丁观察；已退出者需新计划，不把反弹当旧规则没错 |
| 33. 次日继续大跌且不收回 | 趋势与关键位 | 洗盘假设失去支持，按止损/破位退出，不无限忍 |
| 34. 大盘跌，个股相对强但收绿 | 收盘、BBI、关键低点和评分 | 相对强可支持观察，但不能覆盖硬止损或S1 |
| 35. 收绿但收盘比昨日高 | 是否巨量阴、所处高低位 | 正常主升可评分；高位巨量不能用假阴真阳当免死理由 |
| 36. 评分4分，但止损已触发 | 评分用途和预设退出 | 基于防守优先推断，执行止损，评分不是覆盖条件 |
| 37. 只有3分但没有强制退出信号 | 是否主升浪评分策略 | 原库可减半保留余仓；“绝不全卖”有无其他退出条件的边界 |
| 38. 越跌越想补仓摊成本 | 是否有独立新信号和计划 | 原库反对补弱摊薄；旧失败仓不能伪装新B1 |
| 39. 怀疑是超级B1假破位 | 是否旧仓已止损，是否新企稳确认 | 先遵守旧止损，再研究新反转；只有破位不够 |

依据：本组综合时间纪律、七层、评分、持股补丁、击穿对手盘、超级B1，详见 [[06-B1入场与建仓波鉴别]]、[[10-盘中执行与止损计划]]、[[12-持股评分与洗盘应对]]、[[13-放飞止盈与破位退出]]。

## 盈利后、顶部风险与组合变化

| 情景 | 先核对什么 | 原库对应的应对与原因 |
|---|---|---|
| 40. 数到第四块红砖 | 是否按砖而非日K计数 | 至少减半，不能把4+4延续当默认目标 |
| 41. 红砖翻绿 | 当前采用DSZ还是允许一绿的延续定式 | 按既定版本处理，不持仓后切换更宽口径 |
| 42. 加速后出现高位天量大阴 | 与建仓量比较、是否已S1 | 防守优先，按版本至少减半或清仓，不能用MACD红柱拖延 |
| 43. 次高点巨量长阴 | 是否冲顶失败、量大于前高 | 警惕S2，不把二次出货误当二次启动 |
| 44. 新高后阶梯放量阴跌 | 阴线量与阳线量、低点 | 从第一阶开始防守，不每跌一阶就补 |
| 45. 破白线但还没破黄线 | 是否余仓跟白线、波段减仓规则 | 触发白线版本就处理，不能自动等到黄线 |
| 46. 跌破黄线，打算忍一根 | 周线是否多头、是否高位跳空、是否已破硬止损 | 仅事前允许修复的版本可观察一根；周线空头或硬止损不适用 |
| 47. 第二根仍收黄线以下 | 前一根观察是否已消耗 | 原库必须清，不反复重置观察日 |
| 48. S1后重新放量盖过原阴线 | 是后续新证据，不是提前假设 | 原预警可能失效；若已卖出，仍要重新评估买点与风险 |
| 49. 卖出后继续大涨 | 原卖点是否合规 | 复盘信号与执行，不因结果改写当时证据；不立刻追补 |
| 50. ETF破位第二天仍没收回 | 是否牛市ETF策略、原风险位 | 该页要求退出，不能套个股假摔故事 |
| 51. 长期底仓逻辑根本变化 | 原持有逻辑、周线趋势 | 底仓也有退出边界，不用“信仰”替代事实 |
| 52. 指数涨、账户不涨 | 持仓行业集中度、个股趋势和权重贡献 | 检查结构与候选，不因指数涨而反复追涨切换 |
| 53. 同时持有多只同板块票 | 实际风险是否来自同一方向 | 三换三强调跨板块，票多不等于风险分散 |
| 54. 想把卖出的仓位立刻补满 | 是否仍有新买点、环境有无变化 | 空仓和备用金有意义，没有合格信号就不补满 |

依据：本组综合砖形、S1—S5、双线、死亡K线、ETF、底仓与组合管理，详见 [[11-仓位分工与组合轮动]]、[[13-放飞止盈与破位退出]]、[[15-长线底仓与牛市ETF管理]]。

## 原库没有完整规定的执行情形

跳空直接越过止损、无法成交、停牌或价格限制、交易费用、同一时点多个退出条件的完整排序、不同数据源信号冲突、复权切换、资金副图或活跃市值缺公式：当前知识库未覆盖完整执行协议。

本篇不虚构成交价格、损失上限、替代指标或自动化下单办法。发生这些情形时，只能承认规则到实际成交之间仍有缺口，不能声称原策略已保证结果。
