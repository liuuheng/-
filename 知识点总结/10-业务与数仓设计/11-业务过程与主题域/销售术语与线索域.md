# 销售术语与线索域

## 一、销售主链路

```text
流量/访客 → 线索 → 有效线索 → 商机 → 报价/方案 → 合同 → 成交 → 续费/增购
```

核心理解：

- **访客**：只是来过页面，还不一定知道是谁。
- **线索**：表达过兴趣，并且可识别、可跟进的潜在客户。
- **商机**：销售确认有明确需求、预算或成交可能的机会。
- **客户**：已经签约、购买或正式使用服务的对象。

## 二、如何理解线索

线索可以理解为：一个“可能成为客户”的人、公司或需求机会。

它还不是客户，也不一定会成交，只是已经表现出某种兴趣，值得后续运营或销售继续跟进。

### 例子

以酷家乐为例：

- 某装修公司老板看到了酷家乐企业版广告；
- 点进官网；
- 填了手机号和公司名称；
- 选择“想了解企业版报价”。

这时，这个人或这家公司就可以被称为一条线索。

如果他只是看了一眼广告，没有留下任何信息，通常还不能算线索，只能算一次曝光或点击。

## 三、为什么叫线索

“线索”来自销售和侦查语境，表示还不是结论，但指向一个可能结果的信号。

在业务里，这个可能结果就是：这个人或这家公司未来可能会成为客户。

所以它不叫客户，因为还没成交；不叫订单，因为还没付钱；也不一定叫用户，因为可能还没正式使用产品。

它叫线索，是因为它只是一个可追踪、可跟进的潜在成交信号。

```text
广告点击：有点兴趣，但不知道是谁
留下手机号：有了线索
销售确认有预算和需求：变成商机
签合同付费：变成客户
```

线索强调两个点：

- **不确定性**：只是可能成交，不保证成交。
- **可追踪性**：公司已经获得了一些信息，可以继续跟进。

## 四、线索域是什么

线索域是围绕“潜在客户线索”的一组数据主题，不是一张单表。

它通常覆盖：

```text
线索从哪里来、是谁、是否有效、有没有被跟进、有没有转成商机、有没有成交。
```

线索域一般包含：

| 对象 | 说明 |
|---|---|
| 线索 Lead | 一个潜在客户记录 |
| 联系人 Contact | 具体的人，比如老板、设计主管、采购 |
| 公司 Account | 线索背后的企业主体 |
| 来源 Source | 从哪个渠道来的 |
| 活动 Campaign | 哪场活动或投放带来的 |
| 跟进记录 Follow-up | 销售或运营有没有联系 |
| 线索评分 Score | 线索质量高低 |
| 商机 Opportunity | 线索转成明确销售机会 |
| 成交客户 Customer | 最终付费或签约 |

简单理解：

```text
线索域 = Lead + 联系人 + 企业 + 渠道来源 + 活动 + 跟进 + 转化
```

## 五、线索域的数据来自哪里

线索域的数据主要来自“用户表达兴趣之后被捕获下来的信息”，再叠加广告、渠道归因、销售跟进、商机成交等后续数据。

### 1. 广告投放与渠道数据

这部分回答“线索从哪里来”。

| 数据来源 | 典型字段 |
|---|---|
| 广告平台 | 渠道、广告计划、广告组、创意、点击量、消耗、点击成本 |
| 落地页 UTM | utm_source、utm_medium、utm_campaign、utm_content |
| 活动页面 | 活动 ID、报名来源、页面访问、按钮点击 |
| 官网/SEO | 访问来源、搜索词、落地页、访问路径 |

注意：广告点击本身通常还不算线索。用户只是点了广告、浏览页面，更多属于访问行为或营销触点。

一般要等用户留下联系方式、注册、申请试用、预约演示、咨询客服，才会进入线索域。

### 2. 用户主动留资数据

这是线索域最核心的数据来源。

| 行为 | 是否通常形成线索 |
|---|---|
| 点击广告 | 通常不是，只是访问或点击 |
| 浏览官网价格页 | 通常不是，但可作为兴趣行为 |
| 填写预约演示表单 | 是 |
| 申请企业版试用 | 是 |
| 留手机号咨询 | 是 |
| 下载资料并留邮箱 | 是 |
| 报名行业直播 | 是 |
| 在线客服咨询价格 | 是 |
| 注册个人账号 | 看业务规则，可能是线索，也可能只是用户 |

### 3. 产品注册与试用数据

SaaS 公司常把注册、试用、产品内强意向行为也作为线索来源。

常见概念：**PQL = Product Qualified Lead，产品合格线索**。

例如：

- 注册后短时间内创建多个方案；
- 多次使用高清渲染；
- 邀请团队成员；
- 频繁查看企业版权益；
- 触发免费额度限制。

这类用户虽然未必主动找销售，但产品行为显示出较强购买可能。

### 4. 客服、销售、CRM 手工录入

线索也可能来自人工录入或客户互动。

| 来源 | 例子 |
|---|---|
| 销售拜访 | 销售在线下展会认识一个品牌商 |
| 客服咨询 | 用户询问企业版价格 |
| 电话来访 | 客户打电话咨询采购 |
| 代理商推荐 | 渠道商提交客户名单 |
| 老客户转介绍 | 老客户推荐同行公司 |
| 行业名单导入 | 从合法来源整理的潜客名单 |

## 六、客户与线索类术语

| 术语 | 含义 |
|---|---|
| Visitor 访客 | 访问官网、落地页、活动页的人 |
| Lead 线索 | 有兴趣、留下信息、可被跟进的潜在客户 |
| Valid Lead 有效线索 | 联系方式有效，基本符合目标客户画像 |
| MQL | 市场认可线索，由市场侧判断质量较好 |
| SQL | 销售认可线索，由销售判断值得跟进 |
| PQL | 产品合格线索，根据产品使用行为判断有购买可能 |
| Prospect 潜客 | 比普通线索更明确的潜在客户 |
| Customer 客户 | 已购买或签约的客户 |
| KA 大客户 | Key Account，重点客户 |
| ICP | Ideal Customer Profile，理想客户画像 |

## 七、销售过程类术语

| 术语 | 含义 |
|---|---|
| 分配 | 把线索分给销售或团队 |
| 跟进 | 销售联系客户，推动转化 |
| 首响 | 销售首次响应线索的时间 |
| 拜访 | 电话、线上会议、线下面谈等沟通 |
| Demo | 产品演示 |
| 需求确认 | 确认痛点、预算、决策人、采购周期 |
| 报价 | 给客户价格和商务条件 |
| 方案 | 给客户的解决方案或采购方案 |
| 谈判 | 围绕价格、合同、服务条款沟通 |
| 赢单 | 商机成交 |
| 输单 | 商机失败 |
| 搁置 | 暂不推进，但还未明确失败 |

## 八、商机类术语

| 术语 | 含义 |
|---|---|
| Opportunity 商机 | 已确认有成交可能的销售机会 |
| Stage 商机阶段 | 当前销售进展，如沟通、报价、合同 |
| Pipeline 销售管道 | 所有正在推进中的商机集合 |
| Pipeline Amount | 管道内预计成交金额 |
| Win Probability | 成交概率 |
| Close Date | 预计成交时间 |
| Forecast 销售预测 | 预计未来能成交多少金额 |
| Win Rate 赢率 | 商机最终成交比例 |

## 九、收入与合同类术语

| 术语 | 含义 |
|---|---|
| Contract 合同 | 客户签署的购买协议 |
| Order 订单 | 实际购买记录 |
| Payment 回款 | 实际收到的钱 |
| Invoice 开票 | 给客户开具发票 |
| 合同金额 | 合同约定金额 |
| 实收金额 | 实际收到金额 |
| Refund 退款 | 退还客户的钱 |
| Discount 折扣 | 相对标准价的优惠 |
| ARPU/ARPA | 平均每用户/客户收入 |
| ACV | 年合同价值 |
| TCV | 合同总价值 |
| MRR | 月度经常性收入 |
| ARR | 年度经常性收入 |

## 十、转化指标类术语

| 术语 | 含义 |
|---|---|
| CVR 转化率 | 某一步到下一步的转化比例 |
| 线索转商机率 | 商机数 / 线索数 |
| 商机成交率 | 成交商机数 / 商机数 |
| 线索成交率 | 成交客户数 / 线索数 |
| Funnel 漏斗 | 从线索到成交的转化过程 |
| CPL | 单条线索成本 |
| CAC | 获客成本 |
| ROI | 投入产出比 |
| Payback Period | 获客成本回收周期 |

## 十一、SaaS 续费与存量经营术语

| 术语 | 含义 |
|---|---|
| Renewal 续费 | 客户到期后继续购买 |
| Upsell 增购/升级 | 购买更高版本、更多功能 |
| Cross-sell 交叉销售 | 购买另一个产品模块 |
| Expansion 扩容 | 增加席位、账号、门店、容量 |
| Contraction 缩容 | 减少席位、降版本、减模块 |
| Churn 流失 | 到期不续、取消或停止使用 |
| Win-back 召回 | 流失客户重新购买 |
| GRR | 毛收入留存，不含扩容 |
| NRR | 净收入留存，包含扩容、缩容、流失 |
| Health Score 健康度 | 判断续费风险或增购机会的评分 |

## 十二、销售角色类术语

| 术语 | 含义 |
|---|---|
| SDR | 负责线索筛选、初步沟通 |
| BDR | 负责外拓获客、商务开发 |
| AE | 负责推进成交 |
| AM | 负责存量客户续费、增购 |
| CSM | 客户成功，负责客户使用、留存、续费支持 |
| 售前 | 支持方案、演示、技术答疑 |
| 售后 | 交付、培训、问题处理 |
| 渠道销售 | 通过代理商、合作伙伴拓展客户 |

## 十三、数仓建模重点对象

```text
线索 Lead
客户 Account / Customer
联系人 Contact
商机 Opportunity
销售跟进 Activity
合同 Contract
订单 Order
回款 Payment
续费 Renewal
渠道 Source / Campaign
销售人员 Sales Rep
```

最核心的业务链路：

```text
线索产生 → 线索清洗 → 线索分配 → 销售跟进 → 转商机 → 报价 → 签约 → 回款 → 续费/增购
```

## 十四、一句话记忆

销售术语的核心是围绕一条链路展开：

```text
线索是起点，商机是销售确认后的机会，合同/订单是成交结果，续费/增购是 SaaS 存量经营。
```
