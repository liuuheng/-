# 参数配置与日志生产实践

> 目标：参数缺失时在提交阶段快速失败；敏感信息不进入 Flink Web UI、日志或异常；配置来源和覆盖顺序可解释；日志能够关联作业、算子和数据错误。

## 1. `ParameterTool` 的能力边界

`ParameterTool` 适合：

- `--key value`、`--flag` 一类简单参数；
- 从 `Map`、Java Properties、系统属性构建；
- `getInt`、`getLong`、`getBoolean` 等基础类型读取；
- 注册为 Global Job Parameters，让 Rich Function 和 Flink Web UI 看见非敏感配置。

它不负责：

- 自动生成完整帮助文档；
- 子命令和互斥参数；
- 复杂类型绑定；
- Secret 管理；
- 业务范围校验；
- 配置热更新。

所以生产代码不能把 `ParameterTool.fromArgs(args)` 后的若干 `get()` 散落在所有算子中。推荐在入口统一完成“读取 → 合并 → 校验 → 转换为不可变配置对象”，算子只接收已经验证的配置。

## 2. 配置优先级

推荐采用明确、固定的覆盖顺序：

```text
代码默认值 < properties 文件 < 环境变量 < 命令行参数
```

原因：

- 默认值保证本地可运行，但不得给密码设置默认值；
- properties 适合部署环境的非敏感公共配置；
- 环境变量适合容器注入 Secret；
- 命令行便于临时覆盖，优先级最高，但 Secret 会出现在进程参数、提交记录或审计系统中，因此不推荐从命令行传密码。

## 3. 生产级配置对象

配置对象应该满足：值不可变、构建后即合法、可以安全序列化、不在 `toString()` 中泄露 Secret。

```java
package com.example.flink.config;

import java.io.Serializable;
import java.time.Duration;
import java.util.LinkedHashMap;
import java.util.Map;
import java.util.Objects;

public final class JobConfig implements Serializable {
    private static final long serialVersionUID = 1L;

    private final String jobName;
    private final String bootstrapServers;
    private final String inputTopic;
    private final String consumerGroup;
    private final int parallelism;
    private final Duration checkpointInterval;
    private final String databaseUrl;
    private final String databaseUser;
    private final String databasePasswordEnvName;

    public JobConfig(
            String jobName,
            String bootstrapServers,
            String inputTopic,
            String consumerGroup,
            int parallelism,
            Duration checkpointInterval,
            String databaseUrl,
            String databaseUser,
            String databasePasswordEnvName) {
        this.jobName = requireText(jobName, "jobName");
        this.bootstrapServers = requireText(bootstrapServers, "bootstrapServers");
        this.inputTopic = requireText(inputTopic, "inputTopic");
        this.consumerGroup = requireText(consumerGroup, "consumerGroup");
        if (parallelism < 1 || parallelism > 1024) {
            throw new IllegalArgumentException("parallelism must be between 1 and 1024");
        }
        this.parallelism = parallelism;
        this.checkpointInterval = Objects.requireNonNull(
                checkpointInterval, "checkpointInterval");
        if (checkpointInterval.compareTo(Duration.ofSeconds(10)) < 0) {
            throw new IllegalArgumentException(
                    "checkpointInterval must be at least 10 seconds");
        }
        this.databaseUrl = requireText(databaseUrl, "databaseUrl");
        this.databaseUser = requireText(databaseUser, "databaseUser");
        this.databasePasswordEnvName = requireText(
                databasePasswordEnvName, "databasePasswordEnvName");
    }

    private static String requireText(String value, String name) {
        if (value == null || value.trim().isEmpty()) {
            throw new IllegalArgumentException(name + " must not be blank");
        }
        return value.trim();
    }

    public Map<String, String> publicParameters() {
        Map<String, String> values = new LinkedHashMap<>();
        values.put("job.name", jobName);
        values.put("kafka.bootstrap.servers", bootstrapServers);
        values.put("kafka.input.topic", inputTopic);
        values.put("kafka.consumer.group", consumerGroup);
        values.put("parallelism", Integer.toString(parallelism));
        values.put("checkpoint.interval.ms",
                Long.toString(checkpointInterval.toMillis()));
        values.put("database.url", redactJdbcUrl(databaseUrl));
        values.put("database.user", "***");
        // Secret 的值和引用名都不放入 Global Job Parameters。
        return values;
    }

    private static String redactJdbcUrl(String url) {
        // 生产中若 URL 允许 user/password 查询参数，应使用 URI/JDBC URL 专用解析器移除。
        return url.replaceAll("(?i)(password|pwd)=[^;&]*", "$1=***")
                  .replaceAll("(?i)(user|username)=[^;&]*", "$1=***");
    }

    public String getJobName() { return jobName; }
    public String getBootstrapServers() { return bootstrapServers; }
    public String getInputTopic() { return inputTopic; }
    public String getConsumerGroup() { return consumerGroup; }
    public int getParallelism() { return parallelism; }
    public Duration getCheckpointInterval() { return checkpointInterval; }
    public String getDatabaseUrl() { return databaseUrl; }
    public String getDatabaseUser() { return databaseUser; }
    public String getDatabasePasswordEnvName() { return databasePasswordEnvName; }

    @Override
    public String toString() {
        return "JobConfig" + publicParameters();
    }
}
```

这里故意只保存 `databasePasswordEnvName`，而不是密码值。算子可以在 TaskManager 的 `open()` 中解析：

```java
private transient String databasePassword;

@Override
public void open(Configuration parameters) {
    databasePassword = System.getenv(config.getDatabasePasswordEnvName());
    if (databasePassword == null || databasePassword.isBlank()) {
        throw new IllegalStateException("required database Secret is unavailable");
    }
    // 使用密码建立连接后，不要再记录或返回该值。
}
```

这要求 Secret 环境变量存在于每个 TaskManager，而不只是提交客户端。更成熟的平台应让配置保存 Vault/KMS/Secret Manager 的引用，并在 `open()` 使用工作负载身份读取。部分官方 connector 构造器只能直接接收凭证，这时凭证可能进入序列化 JobGraph；必须结合平台的 JobGraph 存储、Web UI、日志和访问控制模型评估，不能声称“没有打印”就等同于“没有泄露”。

这里没有使用 Java `record`。虽然 record 很适合配置对象，但 Flink 1.17 尚未把 Java Record 当成 Flink POJO；Flink 1.19 才增加相应支持。配置对象仅作为用户函数闭包时，可以显式 `implements Serializable` 使用 record，但不要误以为它会自动成为高效的 Flink POJO/State 类型。

## 4. 统一加载与校验

下面代码实现：默认值、可选 properties、环境变量、CLI 覆盖；异常信息只包含键名，不输出 Secret 值。

```java
package com.example.flink.config;

import org.apache.flink.api.java.utils.ParameterTool;

import java.io.IOException;
import java.io.InputStream;
import java.nio.file.Files;
import java.nio.file.Path;
import java.time.Duration;
import java.util.HashMap;
import java.util.Map;
import java.util.Properties;

public final class ConfigLoader {
    private ConfigLoader() {}

    public static JobConfig load(String[] args, Map<String, String> environment) {
        ParameterTool cli = ParameterTool.fromArgs(args);
        Map<String, String> merged = defaults();

        String configFile = cli.get("config");
        if (configFile != null && !configFile.trim().isEmpty()) {
            merged.putAll(readProperties(Path.of(configFile)));
        }

        putIfPresent(merged, "kafka.bootstrap.servers",
                environment.get("JOB_KAFKA_BOOTSTRAP_SERVERS"));
        putIfPresent(merged, "kafka.input.topic",
                environment.get("JOB_KAFKA_INPUT_TOPIC"));
        putIfPresent(merged, "kafka.consumer.group",
                environment.get("JOB_KAFKA_CONSUMER_GROUP"));
        putIfPresent(merged, "database.url", environment.get("JOB_DATABASE_URL"));
        putIfPresent(merged, "database.user", environment.get("JOB_DATABASE_USER"));
        // --config 只是元参数，不进入最终业务配置。
        cli.toMap().forEach((key, value) -> {
            if (!"config".equals(key)) {
                merged.put(key, value);
            }
        });

        if (merged.containsKey("database.password")) {
            throw new IllegalArgumentException(
                    "database.password must not be stored in CLI/properties; "
                            + "use database.password.env");
        }

        return bind(merged);
    }

    private static Map<String, String> defaults() {
        Map<String, String> values = new HashMap<>();
        values.put("job.name", "order-enrichment-job");
        values.put("parallelism", "4");
        values.put("checkpoint.interval.ms", "60000");
        values.put("database.password.env", "JOB_DATABASE_PASSWORD");
        return values;
    }

    private static Map<String, String> readProperties(Path path) {
        if (!Files.isRegularFile(path)) {
            throw new IllegalArgumentException("config file does not exist: " + path);
        }
        Properties properties = new Properties();
        try (InputStream input = Files.newInputStream(path)) {
            properties.load(input);
        } catch (IOException e) {
            throw new IllegalArgumentException("cannot read config file: " + path, e);
        }
        Map<String, String> values = new HashMap<>();
        properties.forEach((key, value) ->
                values.put(String.valueOf(key), String.valueOf(value)));
        return values;
    }

    private static void putIfPresent(
            Map<String, String> target, String key, String value) {
        if (value != null && !value.trim().isEmpty()) {
            target.put(key, value.trim());
        }
    }

    private static JobConfig bind(Map<String, String> values) {
        int parallelism = parseInt(values, "parallelism");
        long checkpointMs = parseLong(values, "checkpoint.interval.ms");
        return new JobConfig(
                required(values, "job.name"),
                required(values, "kafka.bootstrap.servers"),
                required(values, "kafka.input.topic"),
                required(values, "kafka.consumer.group"),
                parallelism,
                Duration.ofMillis(checkpointMs),
                required(values, "database.url"),
                required(values, "database.user"),
                required(values, "database.password.env"));
    }

    private static String required(Map<String, String> values, String key) {
        String value = values.get(key);
        if (value == null || value.trim().isEmpty()) {
            throw new IllegalArgumentException("missing required configuration: " + key);
        }
        return value.trim();
    }

    private static int parseInt(Map<String, String> values, String key) {
        String value = required(values, key);
        try {
            return Integer.parseInt(value);
        } catch (NumberFormatException e) {
            throw new IllegalArgumentException("configuration must be an integer: " + key, e);
        }
    }

    private static long parseLong(Map<String, String> values, String key) {
        String value = required(values, key);
        try {
            return Long.parseLong(value);
        } catch (NumberFormatException e) {
            throw new IllegalArgumentException("configuration must be a long: " + key, e);
        }
    }
}
```

调用方式：

```java
JobConfig config = ConfigLoader.load(args, System.getenv());
```

## 5. 在 Flink 入口中安全使用

```java
package com.example.flink;

import com.example.flink.config.ConfigLoader;
import com.example.flink.config.JobConfig;
import org.apache.flink.streaming.api.CheckpointingMode;
import org.apache.flink.streaming.api.environment.StreamExecutionEnvironment;
import org.apache.flink.api.java.utils.ParameterTool;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

public final class OrderEnrichmentJob {
    private static final Logger LOG =
            LoggerFactory.getLogger(OrderEnrichmentJob.class);

    private OrderEnrichmentJob() {}

    public static void main(String[] args) throws Exception {
        JobConfig config;
        try {
            config = ConfigLoader.load(args, System.getenv());
        } catch (IllegalArgumentException e) {
            // 只记录安全的键名错误，不打印原始 args。
            LOG.error("Invalid job configuration: {}", e.getMessage());
            throw e;
        }

        StreamExecutionEnvironment env =
                StreamExecutionEnvironment.getExecutionEnvironment();
        env.setParallelism(config.getParallelism());
        env.enableCheckpointing(
                config.getCheckpointInterval().toMillis(),
                CheckpointingMode.EXACTLY_ONCE);

        // 只注册脱敏后的参数；Global Job Parameters 会在 Web UI 暴露。
        env.getConfig().setGlobalJobParameters(
                ParameterTool.fromMap(config.publicParameters()));

        LOG.info("Starting Flink job with config={}", config);

        // buildPipeline(env, config);
        env.execute(config.getJobName());
    }
}
```

### 不要这样做

```java
LOG.info("args={}", Arrays.toString(args));               // 可能泄露密码
LOG.info("config={}", parameterTool.toMap());             // 可能泄露密码
env.getConfig().setGlobalJobParameters(rawParameterTool);  // Web UI 可见
```

如果 Secret 来自 Kubernetes Secret、Vault 或云密钥服务，日志中也只能记录“Secret 已加载/缺失”，不能记录值、长度、前缀或哈希。哈希仍可能被字典攻击，且通常没有诊断价值。

## 6. SLF4J 生产实践

### 6.1 占位符与异常

```java
LOG.info("Loaded configuration, topic={}, parallelism={}",
        topic, parallelism);

LOG.warn("Dropping invalid event, reason={}, eventId={}",
        reasonCode, safeEventId);

LOG.error("Database request failed, eventId={}", safeEventId, exception);
```

最后一个参数是 `Throwable` 时，SLF4J 会输出堆栈。不要写：

```java
LOG.error("request failed: " + exception); // 丢失结构，可能没有完整堆栈
```

### 6.2 避免逐条 INFO

在每条事件上打印 INFO 会放大 I/O、日志费用和敏感数据风险。推荐：

- 作业启动、配置摘要、生命周期变化：INFO；
- 可恢复的局部异常：WARN，但必须采样或限频；
- 导致当前请求或作业失败：ERROR；
- 单条数据细节：DEBUG/TRACE，并默认关闭；
- 数量和比例：Flink Metrics，而不是日志刷屏。

简单采样示例：

```java
private transient long invalidCount;

private void recordInvalid(String eventId, String reason) {
    invalidCount++;
    if (invalidCount <= 10 || invalidCount % 10_000 == 0) {
        LOG.warn("Invalid event sampled, count={}, eventId={}, reason={}",
                invalidCount, eventId, reason);
    }
}
```

真实生产更适合使用指标 + 侧输出死信流；本地计数在重启后会归零，不能作为准确业务统计。

### 6.3 MDC 的边界

MDC 基于线程上下文，适合在同步调用链中添加 `jobName`、`operator`、`requestId`。异步回调可能在其他线程执行，不会自动携带 MDC；需要显式复制上下文，并在 `finally` 中清理，否则线程池复用会串数据。

```java
Map<String, String> context = MDC.getCopyOfContextMap();
future.whenComplete((result, error) -> {
    Map<String, String> previous = MDC.getCopyOfContextMap();
    try {
        if (context == null) {
            MDC.clear();
        } else {
            MDC.setContextMap(context);
        }
        // log result
    } finally {
        if (previous == null) {
            MDC.clear();
        } else {
            MDC.setContextMap(previous);
        }
    }
});
```

## 7. 参数单元测试

```java
package com.example.flink.config;

import org.junit.jupiter.api.Test;

import java.util.HashMap;
import java.util.Map;

import static org.assertj.core.api.Assertions.assertThat;
import static org.assertj.core.api.Assertions.assertThatThrownBy;

class ConfigLoaderTest {
    @Test
    void commandLineShouldOverrideEnvironment() {
        Map<String, String> env = validEnvironment();
        JobConfig config = ConfigLoader.load(
                new String[]{"--parallelism", "8"}, env);

        assertThat(config.getParallelism()).isEqualTo(8);
        assertThat(config.getDatabasePasswordEnvName())
                .isEqualTo("JOB_DATABASE_PASSWORD");
    }

    @Test
    void shouldRejectOutOfRangeParallelism() {
        Map<String, String> env = validEnvironment();

        assertThatThrownBy(() -> ConfigLoader.load(
                new String[]{"--parallelism", "0"}, env))
                .isInstanceOf(IllegalArgumentException.class)
                .hasMessageContaining("parallelism");
    }

    @Test
    void stringRepresentationMustNotLeakPassword() {
        JobConfig config = ConfigLoader.load(new String[0], validEnvironment());

        assertThat(config.toString())
                .doesNotContain("secret-from-env")
                .contains("database.user=***");
    }

    @Test
    void shouldRejectRawPasswordOnCommandLine() {
        assertThatThrownBy(() -> ConfigLoader.load(
                new String[]{"--database.password", "do-not-put-this-in-args"},
                validEnvironment()))
                .isInstanceOf(IllegalArgumentException.class)
                .hasMessageContaining("must not be stored");
    }

    private static Map<String, String> validEnvironment() {
        Map<String, String> env = new HashMap<>();
        env.put("JOB_KAFKA_BOOTSTRAP_SERVERS", "kafka-1:9092,kafka-2:9092");
        env.put("JOB_KAFKA_INPUT_TOPIC", "orders");
        env.put("JOB_KAFKA_CONSUMER_GROUP", "order-enrichment");
        env.put("JOB_DATABASE_URL", "jdbc:mysql://db:3306/app");
        env.put("JOB_DATABASE_USER", "flink_user");
        env.put("JOB_DATABASE_PASSWORD", "secret-from-env");
        return env;
    }
}
```

## 8. 何时换用其他参数库

- 参数少、只需键值对：继续使用 `ParameterTool`，外面包一层绑定与校验。
- 需要 `--help`、子命令、互斥选项、强类型绑定：考虑 Picocli。
- 多环境层级配置、列表、嵌套对象：考虑 Typesafe Config；仍需独立 Secret 来源和最终校验。
- 部署平台已经提供统一配置中心：使用平台 SDK，但要明确快照时机。Flink 作业动态配置变更可能改变处理语义，不能把“能热更新”当作“应该热更新”。

## 9. 项目现状提示

当前 `Flink/pom.xml` 使用 `slf4j-log4j12:1.7.25` 且为 `provided`。这意味着运行时实际绑定由集群决定。生产中应检查集群 Flink 发行包的日志实现，不要把第二个 SLF4J binding 打进作业 JAR，否则可能出现 multiple bindings、日志级别失效或类冲突。
