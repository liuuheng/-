# 12 复习检查表

完成一项后，可以手动打勾。

## 使用方法

不要只凭“看过”打勾。每一项至少做到以下一种程度：

1. 不看笔记，用自己的话解释。
2. 手写一个最小代码示例。
3. 能判断一段错误代码为什么有问题。

遇到无法回答的项目，可以回到对应章节末尾的“阅读时常见问题”。第二次阅读时，优先解释“为什么”，再记住 API 写法。
