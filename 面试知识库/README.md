##### 使用说明

- 本知识库按技术组件和知识领域拆分文件，不按原文公司顺序堆叠。
- 相同或近似问法合并为一个知识点，同一题中的连续追问归入同一组 Q&A。
- 知识点不展示来源题号。
- 先看 `处理进度.md` 确认原文章节与段落边界，再继续读取，避免重复计数。

##### 单个知识点结构

每个知识点统一采用以下结构：

1. 知识点名称。
2. 直接使用 `Q：` 和 `A：`，不添加 Q&A 标题。
3. `A：` 必须给出核心结论、实际场景、处理步骤、关键配置或代码位置、异常处理和验证指标，禁止空洞描述。
4. 五级标题 `##### 知识点补充`，记录原理、参数和底层机制。
