##### Python 切片边界

Q：Python 列表或字符串切片的规则是什么？负数步长怎么判断？
A：切片写成 `seq[start:stop:step]`，包含 start、不包含 stop，省略边界时按步长方向取默认值。正步长从左向右；负步长从右向左，例如 `a[::-1]` 是反转，`a[5:1:-1]` 取索引 5、4、3、2。判断时我先看 step 方向，再判断 start 能否沿该方向到 stop，方向相反就为空。step 不能是 0；普通越界边界会被截断而不是报错。

##### 知识点补充

切片通常产生浅拷贝，内部可变对象仍共享引用。大列表频繁切片会复制数据，只需遍历时应改用迭代器或索引区间。

##### Pandas 数据清洗流程

Q：用 Pandas 清洗一批脏数据，你会按什么步骤做，怎样保证可靠？
A：我先读取样本并固定 dtype，避免订单号被推断为数值而丢前导零；再统一列名、编码、日期和枚举，用 isna、duplicated、describe 和分位数检查缺失、重复及异常。缺失值不一律填 0：维度可映射“未知”，指标按业务决定删除、插补或保留；重复数据按业务主键和事件时间取最新。处理后做行数、主键唯一性、金额守恒、空值率和枚举范围校验，把异常行单独输出，并保留原始输入与规则以便重跑。

##### 知识点补充

大文件可用 `read_csv(chunksize=...)` 分块，超过单机边界则交给 Spark。赋值使用 `.loc`，避免链式赋值的视图/副本歧义，并记录每一步过滤行数。
